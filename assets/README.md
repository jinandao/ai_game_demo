## 精灵表布局

```
spr_A.png —— 144 × 288
┌──────┬──────┬──────┐
│ 站立 │ 左脚 │ 右脚 │  row 0 = 面朝下
├──────┼──────┼──────┤
│      │      │      │  row 1 = 朝左
├──────┼──────┼──────┤
│      │      │      │  row 2 = 朝右
├──────┼──────┼──────┤
│      │      │      │  row 3 = 朝上
└──────┴──────┴──────┘
```

只有一行也能用（所有朝向都用它）；只有两帧也能用（站立 + 一帧行走）。

## 注意

- 全部透明底（背景除外）
- 尺寸必须和上表一致，代码按固定帧宽切图
- 换图后**重启游戏**生效（资源有缓存，不做热重载）
